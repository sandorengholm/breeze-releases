# Breeze downloads

This repository hosts Breeze for macOS release archives and the Sparkle update feed. The application source is maintained separately in a private repository.

Download the newest build from [Releases](https://github.com/sandorengholm/breeze-releases/releases). Breeze 0.x is an early alpha. These initial builds are signed for development and are not yet Apple Developer ID notarized.

The `appcast.xml` asset on the latest release lists every available version and its release notes. Each update archive is signed with Breeze's Sparkle EdDSA key.
